# 📊 README --- Gallup / World Happiness Data Analysis

## Project Title

**Modeling Human Well-Being: Exploratory and Predictive Analysis of the
World Happiness Report**

## Overview

This project explores large-scale **human well-being and happiness
data** from the **World Happiness Report / Gallup World Poll**, using
statistical analysis and machine learning techniques.

The goal is not only prediction, but **interpretation**: understanding
how economic, social, and psychological variables relate to subjective
well-being across countries and time.

This project reflects my interest in **human behavior, cognition, and
data-driven social science**.

------------------------------------------------------------------------

## Research Motivation

Happiness scores are often treated as single numbers, but they emerge
from complex interactions between:

- Economic factors
- Social trust and support
- Perceived freedom and corruption
- Psychological and cultural variables

This project asks:

- Which factors most strongly relate to happiness scores?
- How stable are these relationships across countries?
- Can we model and simulate changes in well-being under hypothetical
  conditions?

------------------------------------------------------------------------

## Methods

- Exploratory Data Analysis (EDA)
- Correlation analysis
- Regression and machine-learning-based modeling
- Visualization of cross-country and temporal trends

The emphasis is on **interpretability and reasoning**, not black-box
prediction.
